# Баримт бичиг

backend-ээр хэрхэн дамжихыг тайлбарласан.

| Баримт | Юуны тухай |
| --- | --- |
| [`SPEC.md`](SPEC.md) | Бүтээгдэхүүн ба техникийн шаардлага |

| [`accounts.md`](accounts.md) | Утас/и-мэйлээр нэг удаагийн кодоор нэвтрэх, солих, нууц үг сэргээх, төхөөрөмжүүд |
| [`commerce.md`](commerce.md) | Session, Google нэвтрэлт, сагс, checkout, төлбөр, захиалгын мөчлөг, сэтгэгдэл |
| [`admin.md`](admin.md) | Админ самбар: статистик, захиалга, нөөц, хэрэглэгч, сэтгэгдэл хянах, demo өгөгдөл |
| [`search-api.md`](search-api.md) | Зураг, текст, холимог хайлтын endpoint-ууд |

| `openapi.json` | API-ийн OpenAPI баримт, `make openapi`-ээр үүснэ (commit хийхгүй) |
